# LOCKED ROOM — запуск как Telegram Mini App

Приложение — это обычный статический сайт (`index.html`, `css/`, `js/`). Телеграму нужен
только **HTTPS-адрес**, по которому этот сайт открывается. Бэкенд не нужен: сохранения
лежат в облаке Telegram (CloudStorage) у каждого пользователя.

## 1. Выложить сайт (выбери один способ)

**Netlify Drop — самый простой, без git и терминала**
1. Открой https://app.netlify.com/drop и войди (можно через GitHub или Google).
2. Перетащи туда **всю папку** `locked room` целиком.
3. Через пару секунд получишь адрес вида `https://что-то.netlify.app` — это и есть URL приложения.
4. Чтобы обновить: в настройках сайта → Deploys → снова перетащи папку.

**GitHub Pages**
1. Создай репозиторий на github.com и загрузи в него содержимое папки (кнопка *Add file → Upload files*).
2. Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`.
3. Адрес будет `https://<логин>.github.io/<репозиторий>/`.

## 2. Создать бота и Mini App в @BotFather

1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя и username (должен заканчиваться на `bot`).
2. `/newapp` → выбери своего бота → название, описание, картинка 640×360 (можно скриншот круга) →
   **Web App URL** = адрес из шага 1 → короткое имя (например `room`).
3. Приложение откроется по ссылке `https://t.me/<username_бота>/<короткое_имя>` — её можно кидать друзьям.
4. (Необязательно) кнопка в чате с ботом: `/mybots` → бот → *Bot Settings* → *Menu Button* → тот же URL.

## 3. Что уже сделано под Telegram

- раскрытие на весь экран, тёмные цвета шапки и фона, отступы под «чёлку» и системные панели;
- свайп вниз по полю **не** закрывает приложение (иначе нельзя было бы тянуть связи);
- системная кнопка «Назад» закрывает панели (звук, библиотека, треки);
- вибрация (haptics) на связях, сценах, пэдах и сохранении;
- **сохранения в облаке Telegram** — треки доступны на всех устройствах пользователя;
  вне Telegram сохраняется в браузере (localStorage);
- автосохранение сессии каждые 10 секунд и при сворачивании.

## Важно

- **iPhone:** при включённом беззвучном режиме (переключатель сбоку) Web Audio молчит — сними беззвучный режим.
- Звук включается только после касания — поэтому стартовый экран «tap to start».
- Код трека (`☰ Tracks → Copy code`) можно отправить в чат; получатель вставляет его через `Paste code`.

## Локальная разработка

Встроенный браузер Claude/обычный браузер могут не подгрузить скрипты из `file://`,
поэтому для проверки запусти простой сервер из папки проекта:

```bash
python -m http.server 8765
```

и открой http://localhost:8765
